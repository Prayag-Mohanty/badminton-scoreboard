    Keyboard shortcuts
    • ↑ point to the far player (facing the camera)
    • ↓ point to the near player (back to the camera)
    • A / L point to side 1 / side 2 by name
    • Z or Backspace undo the last point
    • Space play / pause
    • J / K back / forward 5 s (with Shift: 30 s)
    • , / . step one frame (when paused)
    • [ / ] slower / faster

    🎬Make the video here

    You scored this match on YouTube. Choose the original video file (the one you uploaded) and the scoreboard is added to it. Timings match as long as you didn't trim the start of the video in YouTube Studio.

    Creates match-scoreboard.mp4 in this browser. Best in Chrome or Edge on a laptop. A 15-minute 1080p video usually takes 5–15 minutes. Keep this tab open while it runs.

    Starting…

    This browser can't create videos itself. Use Chrome or Edge, or the ffmpeg kit on the right.

    ⚡ffmpeg kit (fastest, any computer)

    Downloads a small ZIP with the scoreboard graphics and a script that adds them to your video using ffmpeg (free). Fastest option and the sound is kept exactly as recorded. Install ffmpeg once, then double-click the script.

    ▶YouTube description

    Includes the result and chapter timestamps for each game. YouTube turns these into chapters automatically.

    Runs entirely in your browser. Your videos are never uploaded.
